Lab 6 of 6 Domain 4 - Plan and Automate Identity Governance P2 Licence

Create an Access Package, Request Access, and Approve

SC-300 Microsoft Identity and Access Administrator - Hands-On Lab

🎯 Learning Objectives

  • Create a catalogue in Entitlement Management
  • Add resources to the catalogue
  • Create an access package with a group as a resource
  • Configure an access policy with approval and expiry
  • Request the access package as an end user and approve as an admin

✅ Pre-Requisites

  • Signed in with your student account
  • Your account has been assigned the Identity Governance Administrator role or your instructor has set up a Catalogue owner role for you
  • Entra ID P2 licence available in the tenant
  • A test user account to request access with (create one from Lab 1 if needed)

🛠️ Lab Steps

📋 Part 1 - Create a Catalogue

  1. Navigate to Entra ID > Identity Governance > Entitlement Management > Catalogs > + New catalog
  2. Set Name to SC300 Lab Catalog
  3. Set Description to Lab catalogue for SC-300 hands-on exercises
  4. Set Enabled to Yes and Enabled for external users to No
  5. Click Create
  6. Exam tip: Catalogs are containers for resources and access packages. You can delegate catalog ownership to non-admins, which is the key benefit for large organisations.

📋 Part 2 - Add a Resource to the Catalogue

  1. Open SC300 Lab Catalog and click Resources > + Add resources
  2. Select Groups and Teams
  3. Search for and select Lab Test Group (create it if it doesn't exist: a Security group named Lab Test Group)
  4. Click Add

📋 Part 3 - Create an Access Package

  1. Navigate to Identity Governance > Entitlement Management > Access packages > + New access package
  2. Set Name to Lab Access Package
  3. Set Catalog to SC300 Lab Catalog
  4. Click Next: Resource roles
  5. Click + Add resource roles, select Groups and Teams, choose Lab Test Group, set role to Member
  6. Click Next: Requests

📋 Part 4 - Configure the Request Policy

  1. Under Who can request access, select For users in your directory > All members (excluding guests)
  2. Under Approval, set Require approval to Yes
  3. Set First approver to your student admin account
  4. Set Request expiration: Access package assignment expires after 30 days
  5. Click Next: Requestor information, skip, click Next: Lifecycle, skip, click Review + create > Create

📋 Part 5 - Request Access as a User

  1. Open a new private browser window and sign in as your test user
  2. Navigate to myaccess.microsoft.com
  3. Find Lab Access Package in the list and click Request
  4. Add a justification: SC-300 lab exercise - requesting access for testing
  5. Click Submit request
  6. Note the request appears as Pending approval

📋 Part 6 - Approve the Request

  1. Return to your admin account and navigate to Identity Governance > Entitlement Management > Requests
  2. Find the pending request from your test user
  3. Click on it and select Approve
  4. Add an approver justification and click Approve
  5. Return to the private browser (test user) and refresh myaccess.microsoft.com
  6. Confirm the access package shows as Delivered
  7. Navigate to the Lab Test Group members list and confirm the test user has been added
  8. Exam tip: Access packages can grant membership to groups, Teams, SharePoint sites, and app roles. The approval flow, expiry, and access review integration are all configurable per policy.
