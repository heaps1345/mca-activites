Lab 1 of 6 Domain 1 - Manage User Identities Free Licence

Create and Manage Users - Including Bulk CSV Import

SC-300 Microsoft Identity and Access Administrator - Hands-On Lab

🎯 Learning Objectives

  • Create individual user accounts in Entra ID
  • Assign licences and roles to users
  • Perform a bulk user import using a CSV file
  • Disable and delete a user account
  • Restore a recently deleted user from the recycle bin

✅ Pre-Requisites

  • Signed in to portal.azure.com or entra.microsoft.com with your student account
  • Your account has been assigned the User Administrator role by your instructor
  • You have a text editor available (Notepad, VS Code) to create the CSV file

🛠️ Lab Steps

📋 Part 1 - Create a Single User

  1. Navigate to Entra ID > Users > All Users > + New User > Create new user
  2. Set User principal name to testuser01@mcacloud.uk (replace with your tenant domain if different)
  3. Set Display name to Test User 01
  4. Under Password, note the auto-generated password or set your own
  5. Click Properties tab and set Job title to Lab Test Account and Department to Labs
  6. Click Review + create then Create
  7. Confirm the user appears in the All Users list

📋 Part 2 - Assign a Role to the User

  1. Click on Test User 01 to open their profile
  2. Navigate to Assigned roles > + Add assignments
  3. Search for and select Reports Reader
  4. Click Add and confirm the role appears under Assigned roles
  5. Exam tip: Know the difference between Entra ID roles (like Reports Reader) and Azure RBAC roles. SC-300 tests both but they are managed separately.

📋 Part 3 - Bulk Import via CSV

  1. Navigate to Entra ID > Users > All Users > Bulk operations > Bulk create
  2. Click Download sample CSV to get the template
  3. Open the CSV in a text editor and add two rows below the header:
  4. version:v1.0,,,,,,,, (leave row 1 as-is)
  5. Row 2: testbulk01@mcacloud.uk,testbulk01,Test Bulk 01,True,,,,,
  6. Row 3: testbulk02@mcacloud.uk,testbulk02,Test Bulk 02,True,,,,,
  7. Save the file and upload it using the Upload your CSV file button
  8. Click Submit and monitor the Bulk operation results - wait for status to show Completed
  9. Exam tip: The bulk import requires the version row at the top. A common exam distractor is a CSV without it - that will always fail.

📋 Part 4 - Disable and Delete a User

  1. Return to All Users and find Test User 01
  2. Click the user, then click Edit properties
  3. Under Settings, set Block sign in to Yes and save
  4. Return to All Users, select Test User 01 and click Delete - confirm deletion
  5. Exam tip: Deleted users are retained for 30 days and can be restored. After 30 days they are permanently gone.

📋 Part 5 - Restore a Deleted User

  1. Navigate to Entra ID > Users > Deleted users
  2. Select Test User 01 and click Restore
  3. Confirm the user reappears in All Users
  4. Delete all test accounts you created (testuser01, testbulk01, testbulk02) to keep the tenant tidy

📝 Exam Relevance

This lab covers SC-300 objective: 'Manage user accounts' under Domain 1. Expect 2-4 questions on user creation, bulk operations, and deletion/restore. Know that soft-deleted users persist for 30 days and that blocking sign-in does not delete the account.
