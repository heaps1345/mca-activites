Register an Application and Configure API Permissions

SC-300 Microsoft Identity and Access Administrator - Hands-On Lab

🎯 Learning Objectives

  • Register a new application in Entra ID
  • Configure redirect URIs
  • Add and grant API permissions (delegated and application)
  • Create a client secret
  • Understand the difference between delegated and application permissions

✅ Pre-Requisites

  • Signed in with your student account with Application Administrator role
  • Basic understanding of OAuth 2.0 concepts (covered in Domain 3 slides)

🛠️ Lab Steps

📋 Part 1 - Register the Application

  1. Navigate to Entra ID > Applications > App registrations > + New registration
  2. Set Name to SC300-Lab-App
  3. Under Supported account types, select Accounts in this organizational directory only (Single tenant)
  4. Under Redirect URI, select Web and enter https://localhost/callback
  5. Click Register
  6. Note the Application (client) ID and Directory (tenant) ID - these are what a developer needs to authenticate
  7. Exam tip: The Application ID is public and used in auth requests. The client secret is private and must be protected. Never put a secret in source code.

📋 Part 2 - Add API Permissions

  1. Click API permissions in the left menu
  2. Click + Add a permission > Microsoft Graph
  3. Select Delegated permissions and search for User.Read - add it
  4. Click + Add a permission > Microsoft Graph again
  5. Select Application permissions and search for User.Read.All - add it
  6. Click Grant admin consent for mcacloud.uk and confirm
  7. Exam tip: Delegated permissions act on behalf of a signed-in user. Application permissions act as the app itself (no user required - used for background services and daemons). Application permissions always require admin consent.

📋 Part 3 - Create a Client Secret

  1. Click Certificates and secrets > + New client secret
  2. Set description to Lab Secret and expiry to 90 days
  3. Click Add
  4. Copy the Value immediately - this is the only time it is shown in full
  5. Important: If you navigate away without copying the secret value, you cannot retrieve it. You would need to delete and recreate it. This is intentional security design.
  6. Note the Secret ID (this is not the secret itself - it is just an identifier)

📋 Part 4 - Review the App in Enterprise Applications

  1. Navigate to Entra ID > Applications > Enterprise applications
  2. Search for SC300-Lab-App and open it
  3. Note this is the Service Principal - the instance of your app in this tenant
  4. Click Permissions and confirm your consented permissions appear here
  5. Exam tip: App registration = the definition. Enterprise application = the service principal (the running instance). One app registration can have service principals in many tenants.

📋 Part 5 - Clean Up

  1. Return to App registrations, find SC300-Lab-App and click Delete
  2. Confirm deletion - this also removes the associated service principal

Tick each item to confirm you have completed the lab successfully.
