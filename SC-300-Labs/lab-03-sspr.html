Configure Self-Service Password Reset (SSPR)

SC-300 Microsoft Identity and Access Administrator - Hands-On Lab

🎯 Learning Objectives

  • Enable SSPR for a group of users
  • Configure authentication methods for SSPR
  • Register authentication methods as an end user
  • Test the SSPR reset flow
  • Review the SSPR audit and usage reports

✅ Pre-Requisites

  • Signed in with your User Administrator or Authentication Policy Administrator student account
  • Access to your mobile phone or personal email to register as an authentication method
  • A test user account to enable SSPR on (use the one your instructor has set up for you, or create testuser01 from Lab 1)

🛠️ Lab Steps

📋 Part 1 - Enable SSPR

  1. Navigate to Entra ID > Protection > Password reset
  2. Under Properties, set Self service password reset enabled to Selected
  3. Click Select group and choose your student group or create a new group called SSPR-Enabled
  4. Click Save
  5. Exam tip: SSPR can be set to None, Selected (a group), or All. In production you always pilot with Selected before rolling out to All.

📋 Part 2 - Configure Authentication Methods

  1. Click Authentication methods in the left menu
  2. Set Number of methods required to reset to 1
  3. Enable Mobile app notification, Email, and Mobile phone
  4. Click Save
  5. Exam tip: Security questions count toward SSPR but are considered weaker than app-based methods. The exam may ask which methods are more secure.

📋 Part 3 - Register as End User

  1. Open a new browser tab or private window and sign in as your test user
  2. Navigate to aka.ms/ssprsetup
  3. Register your mobile phone number or email address as a reset method
  4. Complete the registration wizard
  5. Sign out of the test user account

📋 Part 4 - Test the Reset Flow

  1. Navigate to aka.ms/sspr in your private window
  2. Enter your test user email address and complete the CAPTCHA
  3. Choose your registered method and verify your identity
  4. Set a new password and confirm it
  5. Sign in with the new password to confirm the reset worked
  6. Note: Do not reset your own instructor-provided student account password unless you have been told you can change it.

📋 Part 5 - Review SSPR Reports

  1. Return to your admin account and navigate to Password reset > Audit logs
  2. Filter by Activity: Reset password (self-service) and confirm your test reset appears
  3. Click on the log entry and review the details - note the authentication method used
  4. Navigate to Password reset > Usage & insights to see the SSPR dashboard

Tick each item to confirm you have completed the lab successfully.

📝 Exam Relevance

Covers SC-300 objective: 'Implement and manage a self-service password reset policy' under Domain 1. SSPR is a frequent exam topic - know the licence requirements (free for cloud-only, P1 for writeback), the available authentication methods, and where to find usage reports.
