WHOIS Lookups and Regional Internet Registries

Use WHOIS and RIR databases to identify domain registration details, IP address ownership, ASN assignments, and abuse contacts for a target organisation - all from publicly available sources.

Scenario

You have been engaged to perform a penetration test against Syntex Solutions Ltd. Before any scanning begins, you must conduct passive reconnaissance to map the organisation's internet-facing footprint using WHOIS and RIR lookups. This is entirely passive - no packets are sent to the target.

Learning Objectives
  • Query WHOIS for domain registration and registrant details
  • Identify which Regional Internet Registry (RIR) owns a given IP range
  • Look up ASN assignments to map an organisation's IP space
  • Find abuse and technical contacts from RIR records
  • Understand what WHOIS privacy protection hides and what it does not

Part 1 - Domain WHOIS
1
Query WHOIS for a domain

Use the whois command to retrieve domain registration details. In this lab we use bbc.co.uk as a publicly accessible example target.

whois bbc.co.uk

Look for these key fields in the output: Registrant, Registrar, Creation Date, Expiry Date, Name Servers.

⚠
Many modern domains use WHOIS privacy protection (also called proxy registration). The registrant fields show a privacy service address rather than real contact details. Check the name servers - those are rarely hidden.
Record your findings from the WHOIS output
2
Query a specific WHOIS server

By default whois queries IANA, which redirects to the correct TLD registry. You can specify the server directly with -h.

# Query Nominet directly for .uk domains
whois -h whois.nic.uk bbc.co.uk

# Query Verisign for .com domains
whois -h whois.verisign-grs.com google.com
ℹ
Different TLD registries hold different information. Going directly to the authoritative server often gives more complete data than generic WHOIS tools.
Part 2 - IP Address and ASN Lookups
3
Look up an IP address in WHOIS

WHOIS also covers IP addresses. The response tells you who owns the IP block, the registered organisation, and abuse contact details.

# Look up the owner of a public IP
whois 212.58.244.22

# This is a BBC IP - look for the netname and org fields
What organisation owns this IP block?
4
Find an organisation's ASN

An Autonomous System Number (ASN) identifies all IP ranges belonging to one organisation. Finding the ASN lets you enumerate all their publicly announced IP space.

# Look up ASN ownership
whois -h whois.radb.net AS2818

# Query BGP routing table via a looking glass
# bgp.he.net is a public resource - search for an org name
✓
In a real engagement, use bgp.he.net in your browser to search an organisation by name and see all their ASNs and announced prefixes. This gives you the full IP footprint without any active probing.
What is the organisation name for AS2818?
5
Find prefixes announced by an ASN

Once you have an ASN, you can enumerate all IP prefixes they announce via BGP. This is entirely passive - you are reading publicly available routing data.

# List all routes announced by AS2818
whois -h whois.radb.net -- -i origin AS2818 | grep ^route
How many IP prefixes did you find? List two of them.
Part 3 - Exam-Style Questions
🎯
These are the types of questions that appear in the CPSA written paper. Answer without looking at your notes first.
Q1

An IP address 41.x.x.x is found during passive reconnaissance. Which RIR holds the registration records for this address?

Q2

Which RIR would you query to find ownership records for an IP address in the 200.x.x.x range?

Q3

You query WHOIS for a target domain and get back a privacy service address instead of registrant details. What information can you still reliably obtain from the WHOIS record?

Even with WHOIS privacy enabled, you can reliably obtain: name servers (NS records) - these point to DNS infrastructure you can enumerate; registrar name; creation and expiry dates; domain status flags. Name servers are rarely proxied and often reveal the hosting provider or CDN.
Q4

What is an ASN and why is it useful during passive reconnaissance?

An Autonomous System Number (ASN) uniquely identifies an organisation's network on the internet. During passive recon, it is useful because a single ASN can reveal all IP prefixes announced by that organisation via BGP. This lets you map their entire publicly routable IP footprint from public routing databases without sending any packets to the target.
Q5

You are tasked with passively mapping all IP space belonging to a UK-based company. List the steps you would take using WHOIS and RIR resources.

1. WHOIS the company's domain to get registrant details and name servers. 2. Resolve the domain to get at least one IP address. 3. WHOIS the IP to find the netblock and organisation name. 4. Search RIPE NCC (ripe.net) for the organisation name to enumerate all registered IP ranges. 5. Search bgp.he.net for the organisation's ASN and list all announced prefixes. 6. Cross-reference to confirm ownership. All of this is passive - no packets sent to target.
★
Lab Complete - Key Takeaways: WHOIS is your starting point for passive recon. Domains reveal registrars, name servers, and registration dates. IP lookups reveal the owning organisation and which RIR to query for more. ASNs are the most powerful lever - one ASN number maps an entire organisation's routable IP space. CREST examiners expect you to know all five RIRs and their geographic coverage.
