Part 1 - theHarvester
1
Harvest emails and subdomains with theHarvester

theHarvester queries multiple public sources (search engines, PGP key servers, LinkedIn, Shodan) in one command to collect email addresses and subdomains for a target domain. It is a standard first step in passive recon.

# Basic harvest - query multiple sources
theHarvester -d syntexsolutions.net -b all

# Query specific sources (faster)
theHarvester -d syntexsolutions.net -b google,bing,dnsdumpster

# Limit results per source
theHarvester -d syntexsolutions.net -b google -l 100

# Save results to file
theHarvester -d syntexsolutions.net -b all -f syntex_harvest
ℹ
theHarvester's most reliable sources in 2024: google, bing, dnsdumpster, crtsh (certificate transparency), hunter (API key needed), and shodan (API key needed). Use -b all on engagements but be aware some sources rate-limit quickly.

Part 2 - Shodan
2
Find internet-exposed services with Shodan

Shodan is a search engine for internet-connected devices. It continuously scans the entire internet and indexes banners from open ports - revealing servers, IoT devices, industrial control systems, and misconfigured services.

# CLI search (requires free API key - shodan.io)
shodan search org:"BBC"

# Search for a specific IP
shodan host 20.24.202.6

# Search by hostname
shodan search hostname:syntexsolutions.net

# Useful Shodan dork filters:
# org:"Target Company Name"   - all IPs for an organisation
# ssl:"target.com"            - IPs with target in SSL cert
# http.title:"Admin Panel" org:"Target"
🎯
CREST Exam Focus: Shodan is described as a search engine for internet-connected devices. Key uses in CPSA: finding open ports and service banners without scanning the target, discovering ICS/SCADA systems, locating default-credential devices, and finding servers with known-vulnerable software versions in their banners.

Part 3 - Hunter.io and Email Enumeration
3
Enumerate corporate emails with Hunter.io

Hunter.io scrapes the web for email addresses associated with a domain and identifies the email format pattern used by the organisation (e.g. firstname.lastname@domain.com). This is invaluable for social engineering preparation and spear-phishing assessment.

# Browser: navigate to hunter.io and search for syntexsolutions.net
# Free tier shows first 25 results per month

# API via curl (replace with your free API key):
curl "https://api.hunter.io/v2/domain-search?domain=syntexsolutions.net&api_key=YOUR_KEY"

# Verify a specific email address:
curl "https://api.hunter.io/v2/email-verifier?email=test@syntexsolutions.net&api_key=YOUR_KEY"
✓
Hunter.io often reveals the email format before showing individual addresses (e.g. {first}.{last}@company.com). Once you know the format, you can construct email addresses for any employee you find on LinkedIn - which is why LinkedIn is a critical adjacent OSINT source.

Part 4 - Corporate and Company Sources
4
Query Companies House for UK targets

For UK-registered companies, Companies House at find-and-update.company-information.service.gov.uk provides free public access to company registration data, director names, registered addresses, and filed accounts.

Data available from Companies House:
- Company number and registration date
- Registered address (may differ from operational address)
- Current and past directors (full names and DOB month/year)
- Company accounts (revenue, employee count, assets)
- Persons with Significant Control (ownership structure)
- Filing history
ℹ
Director names from Companies House combined with LinkedIn research and the email format from Hunter.io can produce a highly targeted list of valid executive email addresses - critical intelligence for a social engineering assessment.

Additional OSINT tool reference

A broader toolkit for passive OSINT - know these tools and their primary purpose for the exam.

Shodan
shodan.io
Search engine for internet-connected devices. Finds open ports, service banners, ICS/SCADA systems.
Censys
search.censys.io
Similar to Shodan - internet-wide scans with SSL cert and ASN search. Often finds different hosts.
theHarvester
Kali built-in
Aggregates email addresses and subdomains from Google, Bing, LinkedIn, and other public sources.
Hunter.io
hunter.io
Discovers corporate email addresses and identifies email format patterns for a domain.
LinkedIn
linkedin.com
Employee names, job titles, technologies used, org structure - without any direct contact.
Companies House
companieshouse.gov.uk
UK company registration, directors, filed accounts, ownership structure.
Have I Been Pwned
haveibeenpwned.com
Check whether target domain emails appear in public breach data.
Maltego
maltego.com
OSINT aggregation with visual graph - links people, domains, IPs, and social media.

Q2

Q3

During OSINT against a UK company, you need to find the names of its directors and its registered address without contacting the company. What public resource would you use?

Q4

Explain how you would combine multiple OSINT sources to construct a likely valid email address for a named employee of a target company.

1. Use Hunter.io or theHarvester to identify the company's email format (e.g. firstname.lastname@company.com or f.lastname@company.com). 2. Find employee names via LinkedIn by searching the company name and filtering by department or job title. 3. Cross-reference with Companies House for executive/director names. 4. Construct the email address by applying the identified format to the employee's name. 5. Optionally verify using Hunter.io's email verifier or check Have I Been Pwned to confirm the format is active. This entire process requires no direct contact with the target and produces high-confidence email addresses suitable for a social engineering assessment scope.
