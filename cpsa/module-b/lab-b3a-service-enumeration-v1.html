Service and Protocol Enumeration

This lab covers protocol-level enumeration before you use nmap. You will query DNS records, attempt SMB null sessions, perform anonymous LDAP binds, and query SNMP. Each section produces intelligence that shapes your attack approach. All commands use <TARGET_IP> - substitute the IP your instructor assigns.

Part 1 - DNS Enumeration
ℹ
DNS runs on port 53. It is one of the richest sources of intelligence in a pentest. A misconfigured DNS server will hand you the complete internal hostname list in a single query.
1
Query DNS record types against the target

Use dig to query the target's DNS server directly. This tells you what records are exposed and what services are running.

# Query A record - what IP does this hostname resolve to?
dig @<TARGET_IP> syntex.local A

# Query all record types
dig @<TARGET_IP> syntex.local ANY

# Query MX records - mail servers
dig @<TARGET_IP> syntex.local MX

# Query NS records - name servers
dig @<TARGET_IP> syntex.local NS

# Query TXT records - often SPF, DMARC, or internal notes
dig @<TARGET_IP> syntex.local TXT
Record your DNS findings
2
Attempt a DNS zone transfer (AXFR)

A zone transfer copies the entire DNS zone to another server - normally used by secondary DNS servers. If a DNS server does not restrict zone transfers to authorised secondaries, any host can request the full hostname list. This is a critical misconfiguration.

# Attempt AXFR zone transfer
dig axfr @<TARGET_IP> syntex.local

If the transfer succeeds, you will see every DNS record in the zone - hostnames, IPs, mail servers, internal services. If it fails, you will see Transfer failed or REFUSED.

Zone transfer result
🎯
CREST Exam Link: DNS zone transfers (AXFR) are a classic misconfiguration. The exam will test whether you know the record type name, the tool (dig), and the flag (-axfr). It may also ask what information a successful transfer reveals.
Part 2 - SMB Enumeration
⚠
SMB (port 445) is one of the most dangerous services to expose. Null sessions - anonymous connections with no credentials - allow share enumeration on misconfigured Windows hosts. Modern Windows defaults block this, but legacy configurations and misconfigurations still appear regularly.
3
List SMB shares with a null session

A null session uses an empty username and password. The -N flag tells smbclient not to prompt for a password.

# List shares on the target - null session (no credentials)
smbclient -L //<TARGET_IP> -N

# If the target is on a Windows domain, specify it
smbclient -L //<TARGET_IP> -N -W SYNTEX

Shares ending in $ are hidden administrative shares (C$, ADMIN$, IPC$). IPC$ is the inter-process communication share - connecting to it with a null session enables user enumeration on some configurations.

SMB enumeration results
4
Connect to a share and list contents

If you found any readable shares, try connecting. The -N flag skips the password prompt for anonymous access.

# Connect to a share anonymously
smbclient //<TARGET_IP>/<SHARENAME> -N

# Once connected, useful commands:
# ls        - list files
# get file  - download a file
# exit      - disconnect
✓
On a real engagement, finding a world-readable share is always worth documenting even if it looks empty. Configuration files, old backups, and forgotten scripts have all been found on "empty" SMB shares. Always run ls -la equivalent to show hidden files.

Part 3 - LDAP Anonymous Bind
ℹ
LDAP (port 389) is the query interface for Active Directory. An anonymous bind - connecting without credentials - is allowed by default on some older AD configurations. Even a failed anonymous bind confirms that LDAP is running, which means Active Directory is present.
5
Attempt an LDAP anonymous bind

ldapsearch queries LDAP directories. The -x flag means simple authentication (not SASL). The empty bind DN (-D "") and no password (-w "") attempt an anonymous bind.

# Attempt anonymous bind and query the base DN
ldapsearch -x -H ldap://<TARGET_IP> -b "" -s base

# If the base DN succeeds, try enumerating users
ldapsearch -x -H ldap://<TARGET_IP> -b "DC=syntex,DC=local" "(objectClass=user)" sAMAccountName

# Enumerate groups
ldapsearch -x -H ldap://<TARGET_IP> -b "DC=syntex,DC=local" "(objectClass=group)" cn

If anonymous bind is blocked, you will see ldap_bind: Inappropriate authentication (48). This still tells you LDAP is running. If it succeeds, you will see the directory structure and potentially a full user list.

LDAP enumeration results
🎯
CREST Exam Link: The exam will ask what you can enumerate via LDAP on an Active Directory domain controller. The answer includes user accounts, groups, group membership, computer accounts, and password policy. Even with authentication required, Kerberoasting abuses the authenticated LDAP interface.
Part 4 - SNMP Enumeration
⚠
SNMP runs on UDP port 161. SNMPv1 and v2c use community strings as the only authentication. The default read community string is public. If this is not changed, an attacker can read the full device configuration including interface IPs, running processes, and software versions.
6
Query SNMP with the default community string

snmpwalk walks the SNMP MIB tree and returns everything the device exposes. We use the default community string public and SNMPv2c.

# Walk the full SNMP tree with default community string
snmpwalk -v2c -c public <TARGET_IP>

# Query specific OIDs - system description
snmpwalk -v2c -c public <TARGET_IP> 1.3.6.1.2.1.1.1.0

# Running processes
snmpwalk -v2c -c public <TARGET_IP> 1.3.6.1.2.1.25.4.2.1.2

# Network interfaces
snmpwalk -v2c -c public <TARGET_IP> 1.3.6.1.2.1.2.2.1.2

If the community string is correct you will see a large amount of output. If it is wrong or SNMP is not running you will see Timeout: No Response from <TARGET_IP>.

SNMP enumeration results
✓
If public does not work, try private (the default write community string), manager, and the target organisation's name. Community strings are often set to company names or abbreviations.

Exam-Style Questions
Q1

What DNS query type requests a full copy of a zone's records from a DNS server?

Q2

What is a null session in the context of SMB, and why is it a security concern?

A null session is an anonymous connection to an SMB server using an empty username and password. It is a security concern because on misconfigured systems it allows an unauthenticated attacker to enumerate shares, user accounts (via IPC$), and sometimes read sensitive file content - all without any credentials.
Q3

SNMP is running on a target. The community string public returns data. What security version of SNMP is this, and what is the primary weakness?

SNMPv1 or v2c - both use community strings as cleartext authentication passed in every packet. The community string travels in plaintext and can be captured by anyone on the network. SNMPv3 uses proper authentication (MD5/SHA) and optionally encryption (DES/AES) to address this. Using the default public community string is a critical misconfiguration.
Q4

What port does LDAP run on, and what does a successful anonymous bind tell you about the target?

LDAP runs on port 389 (636 for LDAPS). A successful anonymous bind means the server allows unauthenticated queries to the directory. On Active Directory, this can expose the full user list, group memberships, computer accounts, and password policy without any credentials. The presence of LDAP itself strongly suggests Active Directory is in use.
Q5

You run dig axfr @<TARGET_IP> syntex.local and receive a Transfer failed: REFUSED response. What does this tell you, and is this good or bad from a security standpoint?

The DNS server is running and responded (you confirmed port 53 is open). The REFUSED response means the server is correctly configured to only allow zone transfers to authorised secondary DNS servers - this is good security practice. A successful transfer would be a misconfiguration. REFUSED does not mean DNS is broken - normal individual record queries will still work.
✓ Lab Complete - Key Takeaways
Protocol-level enumeration gives you information that nmap cannot. A DNS zone transfer hands you the complete hostname list. An SMB null session gives you share names and potentially file access. An LDAP anonymous bind reveals the directory structure. SNMP with the default community string exposes the device configuration. By the time you open nmap, you should already have a picture of what is running. The B4 scanning labs build on this - nmap confirms ports, but enumeration tells you what to do with them.
