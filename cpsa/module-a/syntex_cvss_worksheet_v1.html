F-01
Unauthenticated Remote Code Execution via Apache Struts
SYNTEX-LNX01 - 10.1.53.39 - Port 8080/TCP
The web application running on port 8080 is built on Apache Struts 2.5.16, which is vulnerable to CVE-2018-11776. The vulnerability exists in the Struts OGNL expression evaluation and allows a remote, unauthenticated attacker to execute arbitrary OS commands on the server by sending a specially crafted HTTP request. No authentication is required and no user interaction is needed. A successful exploit gives the attacker command execution as the www-data user, but a SUID binary on the system allows immediate privilege escalation to root, effectively compromising the underlying server and any data it holds.
Evidence
curl -v http://10.1.53.39:8080/index.action \
  -H 'Content-Type: %{(#_=@org.apache.struts2.ServletActionContext@getResponse())'

HTTP/1.1 200 OK
uid=33(www-data) gid=33(www-data) groups=33(www-data)

# Post-exploitation - SUID binary found
find / -perm -4000 2>/dev/null
/usr/bin/find
find / -exec /bin/sh -p \; -quit
# id
uid=0(root) gid=0(root) groups=0(root)

F-02
SMB Null Session - Password Policy Enumeration
SYNTEX-DC01 - 10.0.29.131 - Port 445/TCP
The Domain Controller accepts SMB null sessions, allowing an unauthenticated network attacker to enumerate the domain password policy without any credentials. The attacker can determine the minimum password length, lockout threshold, and lockout duration. This information assists in planning brute-force and password spray attacks by allowing the attacker to stay below the lockout threshold. The vulnerability does not directly disclose any credentials or allow modification of data, but it reduces the effort required for subsequent attacks. No user interaction is required and no privileges are needed.
Evidence
crackmapexec smb 10.0.29.131 --pass-pol -u '' -p ''

SMB  10.0.29.131  445  SYNTEX-DC01  Password history length: 0
SMB  10.0.29.131  445  SYNTEX-DC01  Maximum password age: Not Set
SMB  10.0.29.131  445  SYNTEX-DC01  Password Complexity Flags: 000000
SMB  10.0.29.131  445  SYNTEX-DC01  Lockout Threshold: 0
SMB  10.0.29.131  445  SYNTEX-DC01  Lockout Duration: Not Set

F-03
Cleartext FTP Credentials in Configuration File
SYNTEX-LNX01 - 10.1.53.39 - Filesystem
Following initial access to SYNTEX-LNX01 with low-privileged credentials, a world-readable configuration file was discovered containing plaintext FTP credentials for the organisation's backup server. The credentials allow an authenticated attacker with local access to escalate their reach to the backup infrastructure. Exploiting this requires local access to the server (already obtained via another vulnerability). The backup server stores full server snapshots including the Active Directory database. Integrity and availability of the backup server could be affected, but the attacker cannot modify data on the system where the credentials were found. The vulnerability does not change the scope of the attack beyond the component where it was found.

F-04
Weak SSH Password - Root Login Permitted
SYNTEX-LNX01 - 10.1.53.39 - Port 22/TCP
SSH is accessible from the network on port 22 and the root account is permitted to log in directly. The root account uses the password toor (root reversed), a well-known default. An unauthenticated remote attacker can authenticate directly as root using this trivially guessable password, gaining full administrative control of the Linux server. No user interaction is required. Root access gives complete control over the system including all data, processes, and configuration - full compromise of confidentiality, integrity, and availability. The attack does not change scope beyond the target system itself.
Evidence

F-05
Kerberoastable Service Account - Weak Password Hash
SYNTEX-DC01 - 10.0.29.131 - Active Directory
Using the supplied domain credentials (jsmith / Password1), a Kerberoasting attack was performed. The service account svc_mssql has a weak password and its Kerberos service ticket hash was extracted and cracked offline in under 2 minutes. The cracked credentials (svc_mssql:Mssql2019!) provide access to the MSSQL service and the account has local admin rights on SYNTEX-DC01. Kerberoasting requires valid domain credentials (low privileges) to request the ticket. The attack is performed entirely from the attacker's machine with no interaction on the target. The cracked credentials grant access beyond the initial component (the Domain Controller itself and the SQL service), changing the scope of impact.

F-06
Self-Signed TLS Certificate on Admin Portal
SYNTEX-LNX01 - 10.1.53.39 - Port 8443/TCP
The administrative web portal on port 8443 uses a self-signed TLS certificate that has expired. This means that users accessing the portal receive browser security warnings and are susceptible to man-in-the-middle attacks if they proceed. However, exploitation requires an attacker to be on the same network segment as the victim (adjacent network position) and requires the user to interact by accepting the certificate warning and proceeding. If exploited, an attacker positioned on the network could intercept credentials submitted to the admin portal. Integrity and availability are not directly affected. The scope of the vulnerability stays within the affected component.
Evidence
openssl s_client -connect 10.1.53.39:8443 2>/dev/null | openssl x509 -noout -text

Certificate:
    Issuer: CN=localhost
    Subject: CN=localhost
    Validity:
        Not Before: Jan  1 00:00:00 2022 GMT
        Not After : Jan  1 00:00:00 2023 GMT  [EXPIRED]
    Signature Algorithm: sha256WithRSAEncryption
    Self-signed certificate in certificate chain
