Syntex Engagement Pack

Interactive document review - 6 tabs
Live

A complete fictional engagement pack for the Syntex Solutions Ltd penetration test. Students review all six pre-engagement documents and answer knowledge check questions embedded within each document section.

  • Identify the six documents that comprise a professional engagement pack
  • Explain the legal function of the Permission to Test Letter under CMA 1990 s.1
  • Distinguish the Scope of Work from the Rules of Engagement
  • Extract key technical details from the Network Overview (IPs, services)
  • Locate the emergency escalation contact and testing hours from the RoE

A2

Model Answer Findings Report

Annotated pentest report - 18 findings
Live

A complete model answer penetration test report for the Syntex engagement. Contains 18 findings across four severity levels with full evidence, CVSS vectors, remediation guidance, compliance mapping, and an executive summary. Used as a reference and marking guide for Lab A3.

  • Identify the seven sections of a professional pentest report
  • Distinguish executive summary content from technical finding content
  • Read and interpret a CVSS v3.1 vector string
  • Understand the structure of a technical finding (ID, title, severity, CVSS, description, evidence, remediation)
  • Map findings to PCI DSS, UK GDPR, and FCA SYSC requirements
CPSA Objective A3 - Reporting and Communication
Finding Count 18 total - 3 Critical / 7 High / 6 Medium / 2 Low
Critical Findings Kerberoasting (9.9), Weak SSH Root Password (9.8), Apache Struts RCE CVE-2017-5638 (9.8)
Report Sections Cover, Executive Summary, Risk Summary Table, Scope and Methodology, Technical Findings, Compliance Impact, Remediation Roadmap
Key Feature Full compliance mapping table (PCI DSS v4.0, UK GDPR, FCA SYSC, CMA 1990) - collapsible finding cards with CVSS badges

A3

Student Report Template

Fillable HTML form with localStorage autosave
Live

An interactive fillable report template for students to write up their Syntex findings. Mirrors the structure of the model answer report (Lab A2). All fields autosave to localStorage. Students fill in the executive summary, risk table, and individual findings with embedded CVSS v3.1 calculator per finding.

  • Practise structuring a professional pentest report from scratch
  • Write an executive summary targeted at a non-technical audience
  • Complete a risk summary table with severity ratings and CVSS scores
  • Document findings with evidence placeholders, description, and remediation
  • Calculate and record CVSS v3.1 vector strings for own findings
CPSA Objective A3 - Reporting and Communication
Form Fields Consultant name, date, classification, executive summary textarea, risk table rows, 5 pre-templated finding sections with embedded CVSS calculator each
Autosave All fields autosave to localStorage on input - restored on page reload
Assessment Use Student prints or exports completed report - compare against Lab A2 model answer for marking

A4

CVSS v3.1 Scoring Worksheet

Interactive calculator - 6 scenarios
Live

Six finding scenarios drawn from the Syntex engagement, each requiring students to select all 8 CVSS v3.1 base metrics and calculate a score. Live score calculated as metrics are selected. Model answers toggle to reveal correct vector strings, scores, and severity rationale.

  • Select correct values for all 8 CVSS v3.1 base metrics (AV, AC, PR, UI, S, C, I, A)
  • Understand the Scope metric and when Scope:Changed applies (e.g. Kerberoasting)
  • Map vulnerability characteristics to correct Attack Vector values
  • Interpret the CVSS severity bands (Critical/High/Medium/Low/None)
  • Write correct CVSS:3.1/AV:.../... vector strings
CPSA Objective A4 - Vulnerability Assessment and CVSS
Scenarios 6 findings: Kerberoasting (9.9 Critical), Weak SSH Root (9.8 Critical), Apache Struts RCE (9.8 Critical), SMBv1 EternalBlue (9.8 Critical), Cleartext FTP Creds (7.5 High), Self-signed Cert (5.3 Medium)
Calculator Feature Live CVSS score calculated as each metric is toggled - colour-coded severity band (Critical/High/Medium/Low)
Model Answers Expandable per scenario - shows correct metric selections, full vector string, score, and explanatory notes
